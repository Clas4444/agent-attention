# Documentation

Use current guides for today's behavior. Historical reports retain their original
versions, measurements and limits.

| Need | Start here |
|---|---|
| Choose/install a skill | [Skill catalog](../skills/README.md) |
| Apply a task profile | [Attention profiles](guides/attention-profiles.md) |
| Design an independent attention plan | [Attention setup](guides/attention-setup.md) |
| Attach attention to an existing graph | [Optional workflow integration](guides/workflow-integration.md) |
| Try level settings without execution | [Offline playground](playground/index.html) |
| Find measured results and their limits | [Results](testing/results.md) |
| Find older evidence by date | [Testing/report index](testing/README.md) |
| Run controlled benchmarks | [Benchmark guide](../benchmarks/README.md), [campaign protocol](testing/campaigns.md) |
| Maintain sources, names and links | [Repository layout](development/repository-layout.md) |
| Check compatibility and release changes | [Release notes](development/release.md), [changelog](../CHANGELOG.md) |

Guides use lowercase kebab-case filenames. Reports and paired JSON captures live
under `testing/reports/YYYY-MM-DD/` with matching stems. Conventional entry names
such as README.md and SKILL.md remain uppercase. The
[path migration map](development/path-migrations.json) maps the former locations;
old commit permalinks still resolve the original snapshots.
