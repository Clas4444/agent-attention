# batch — decomposition and intermediate feedback, not batch size

Load only this selected axis when its compact directive needs clarification.
Level3 is the existing workflow; lower/higher allocate less/more of this quantity.
Mandatory/risk-triggered checks, authority and changed-contract reconciliation remain.

| Level | Observable guidance |
|---|---|
| 1 | Group straightforward related changes; use one acceptance check without optional intermediate decomposition. |
| 2 | Use a few coherent work items; inspect only consequential intermediate boundaries. |
| 3 | Use the existing skill batch size for a complete bounded work item. |
| 4 | Split related changes at dependency boundaries and inspect each meaningful intermediate result. |
| 5 | Decompose consequential work into explicit reversible steps; inspect each result before the next dependent change. |

This axis is not a token target, route selector or minimum-iteration rule.
A temporary override inherits task axes and expires on scope exit.
